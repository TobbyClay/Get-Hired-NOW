# Application review

Present the exact employer/requisition, selected claims and sources, original
resume identity, current question wording/answers, unresolved gates, destination
and action. Do not request approval for an incomplete or contradictory packet.

The trusted human interface obtains explicit confirmation after showing this
preview, then creates a one-use 15-minute context grant. Re-inspect immediately
before execution. Candidate, job, form, policy, destination or artifact changes
require another review. The grant cannot waive a hard gate.

Use Workflow.submit. A dry-run result is SIMULATED. Actual acceptance must have
an exact-job employer receipt. A crash or timeout is unresolved and requires
reconciliation, even when a user approved the initial attempt.
