# Job-search workflow

1. If no candidate exists, run the setup conversation. Collect and confirm facts;
   never synthesize a profile from machine context or another person's records.
2. Load explicit state and current permissions. Assign bounded work with exact
   source/employer scope and one owner for submissions/shared state.
3. Discover through JobSource. Persist identity, source evidence and duplicate
   outcomes. Verify actual role geography and distinguish hard requirements.
4. Evaluate grounded evidence. Reject known hard mismatches; route unknown facts,
   material conflicts and contradictory evidence to the person.
5. Research only unresolved material questions. Refresh the exact posting through
   the state interface; changes invalidate old packets.
6. Prepare within the current mode. Map the form before investing in writing. Keep
   supported claims, original resume, questions and sources in a private packet.
7. Review/authorize through the human interface or explicit autonomous policy.
   Hard gates always remain. Reserve before transport, then record actual outcomes.
8. Reconcile exact receipts and update authorized trackers. Report sightings,
   qualified roles, packets, attempts, simulations and confirmations separately.

Conversation history is a discussion aid. SQLite is the workflow source of truth.
