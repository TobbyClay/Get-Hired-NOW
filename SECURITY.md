# Security and privacy reports

Do not post live credentials or personal candidate data in a public issue.
Use the repository's private vulnerability reporting channel if enabled. Otherwise,
open a minimal issue asking for a private reporting channel without disclosing the
sensitive payload. Reproduce with fictional inputs where possible.

The current release is a trusted local workflow, not a browser sandbox or encrypted
candidate vault. See the documented trust boundaries and privacy scanner limits
in `docs/safety-and-approval.md`.
