# Contributing

Keep contributions small and grounded in an observable workflow behavior. Include
a fictional regression case for permission, evidence, state or adapter changes.

Run the unittest suite, offline demo, privacy scan and `git diff --check`. CI uses
Python 3.10 and 3.13 on Linux and Windows. The runtime uses only the standard library.

Do not attach real resumes, receipts, candidate transcripts, tokens, personal
tracker exports or browser captures to public issues or pull requests. Describe
failures using fictional inputs and generic paths. The MIT license applies to
new contributions; retain required attribution if adding third-party code.

Document whether a feature is a tested local capability, a mocked integration or
a live integration. Do not claim automated hiring success from fixture results.
