# Tracker

Read persisted sightings, evaluations, packets, attempts and receipts. Keep these
evidence classes distinct. A public form map, click, prepared document or simulated
result is not employer acceptance. An explicit validation/security failure is not
a hiring rejection. Do not erase earlier confirmed acceptance after a later event.

Deduplicate exact requisitions and preserve unresolved attempts. Propose changes
with supporting evidence to the record owner. Use the guarded tracker adapter for
authorized remote exports; the bundled CSV adapter is only a local observation log.

Do not infer counts from chat memory, change candidate facts, retry an application,
send outreach or claim a remote record changed without a provider result.
