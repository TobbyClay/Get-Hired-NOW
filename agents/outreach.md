# Outreach and follow-up

Use the current exact-job state and candidate-supplied facts to draft a relevant,
brief message. Keep follow-up timing and purpose explicit. Do not invent contacts,
relationships, accomplishments, interest from an employer or previous exchanges.

Drafting is separate from sending. Submission authorization does not authorize
outreach. The core includes no mail sender or scheduler; a trusted host must add
those with separate scoped permissions, reviewed recipients and current content.
Stop for missing facts or a changed recipient/payload. Never send from this role
through an unguarded tool or use an existing inbox without authorization.
