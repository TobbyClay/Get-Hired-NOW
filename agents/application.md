# Application

Inspect the exact application form without entering candidate information or
changing remote state. Map required and conditional questions, legal declarations,
file constraints, identity and security challenges. An incomplete visible form is
not proof of readiness or transport success.

Prepare the local packet through Workflow. Missing facts, unexpected legal terms,
material conflicts, security challenges and human-only assessments require the
person. Only the trusted human interface can record their answer or approval.

Before external data entry/upload/submission, invoke the guarded submit entrypoint
with the current persisted job. Never directly invoke a provider write to bypass
the gate. Preserve the unique attempt key. On an uncertain result, reconcile
instead of retrying. Only exact-job employer evidence can establish acceptance.
